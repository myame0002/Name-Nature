# Google Vision AI + Wikipedia API の評価

## アイデアの概要

- **Google Vision AI**: 画像からラベルを検出（「花」「鳥」など）
- **Wikipedia API**: 検出されたラベルから詳細情報を取得

## 詳細評価

### 1. Google Vision AI の能力

#### できること
- ✅ 画像のラベル検出（「flower」「bird」「insect」など）
- ✅ 物体認識（一般的なカテゴリ）
- ✅ シーン認識（「forest」「garden」など）
- ✅ 高い信頼性と安定性

#### できないこと（重要）
- ❌ **特定種の識別**: 「オオイヌノフグリ」や「ベニテングタケ」のような具体的な種名は識別できない
- ❌ **分類学的情報**: 科、属、種の階層構造は得られない
- ❌ **日本語対応**: ラベルは主に英語

#### 実際の出力例
```
入力: オオイヌノフグリの写真
出力: ["flower", "plant", "nature", "purple flower", "blossom"]
```

**問題**: 種名までは特定できない。

### 2. Wikipedia API の能力

#### できること
- ✅ 豊富な記事データ（日本語対応）
- ✅ 生物の詳細情報
- ✅ 画像、説明文、分類情報

#### できないこと・課題
- ❌ **構造化されていない**: データベース形式ではなく、自由文
- ❌ **検索の精度**: ラベルから正確な記事を探すのが難しい
- ❌ **複数候補の提示**: 曖昧な検索には不向き
- ❌ **レート制限**: 大量のリクエストには制限あり

#### 実際の課題
```
Google Vision出力: "flower"
Wikipedia検索: "flower" → 曖昧すぎて正しい記事が見つからない

"purple flower" → まだ曖昧
"Veronica persica" → これが出れば理想だが、Google Visionは出力しない
```

### 3. コスト評価

#### Google Cloud Vision AI
- **無料枠**: 月1,000リクエスト
- **有料**: 1,001リクエスト以降、$1.50/1,000画像
- **推定コスト**: 1日100枚使用 → 月3,000枚 → $3.00/月（約450円）

#### Wikipedia API
- **完全無料**
- ただし、レート制限あり（ Polite usage policy）

**総合コスト**: 月額約500円程度（Google Visionのみ）

### 4. 実装の複雑さ

#### 必要な処理
1. Google Vision API呼び出し
2. ラベルの解析とフィルタリング
3. Wikipedia APIでの検索
4. 複数候補のマッチング
5. 結果のランク付け

#### 課題
- ラベルから適切なWikipedia記事を探すロジックが複雑
- 複数候補の提示が難しい（iNaturalistは3つの候補を返す）
- 日本語/英語のマッピングが必要

### 5. 識別精度の比較

| サービス | 特定種識別 | 日本語対応 | 複数候補 | 分類情報 |
|----------|-----------|-----------|---------|---------|
| iNaturalist API | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ |
| Google Vision + Wikipedia | ⭐ | ⭐⭐ | ⭐ | ⭐⭐ |
| Plant.id | ⭐⭐⭐（植物のみ） | ⭐⭐ | ⭐⭐ | ⭐⭐⭐ |

## 結論

### 残念ながら、この組み合わせは**現実的ではありません**

#### 理由

1. **識別精度が大幅に低下**
   - Google Visionは「花」までは分かっても「オオイヌノフグリ」までは分からない
   - ユーザー体験が大幅に低下

2. **Wikipedia APIとの連携が困難**
   - 曖昧なラベルから正確な記事を探すのが難しい
   - 複数候補の提示がほぼ不可能

3. **iNaturalist APIの優位性**
   - iNaturalistは生物識別に特化したAI
   - コミュニティデータによる高精度
   - 詳細な分類学的情報

### なぜこのアイデアが生まれたか？

理解できます：
- ✅ Google Visionは身近で信頼できる
- ✅ Wikipediaは無料で情報豊富
- ✅ API利用のハードルが低い

**しかし、生物識別という専門分野では、iNaturalistの方が圧倒的に適している**

## 現実的な代替案（再評価）

### 1. **Plant.id API**（最も現実的）
- 植物識別に特化
- 無料枠あり
- 種レベルまで識別可能
- **花カテゴリのみなら実用的**

### 2. **iNaturalist APIを維持**（最善）
- アプリ所有者申請を目指す
- 長期トークン取得
- 最高の識別精度を維持

### 3. **ハイブリッド方式**
- 花: Plant.id API
- キノコ・鳥・昆虫: 手動入力
- 次第にAI識別カテゴリを増やす

## 最終的な推奨

**残念ながら、「Google Vision + Wikipedia」は現実的ではありません。**

**代わりに**:
1. **短期目標**: Plant.id APIで花を識別（無料）
2. **中期目標**: アプリ所有者申請（改善ID10個を目指す）
3. **長期目標**: iNaturalist長期トークンで全カテゴリを識別

これが最も現実的な道筋です。
