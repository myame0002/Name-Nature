# iNaturalist で改善IDを追加する方法

## 概要

「改善ID」とは、他のユーザーの観察記録に対して、より正確な同定（Identification）を追加することです。本ドキュメントでは、その方法を説明します。

## 事前準備

1. iNaturalistにログインしていること
2. アカウントが2ヶ月以上経過していること（あなたは2026年4月7日登録なのでOK）

## 改善IDを追加する手順

### ステップ1: 同定が必要な観察を見つける

1. **iNaturalistのホームページ**にアクセス
   - https://www.inaturalist.org

2. **「Explore」または「観察を探す」**をクリック

3. **フィルタリング**（オプション）:
   - あなたが詳しいカテゴリ（花、キノコ、鳥、昆虫など）で絞り込み
   - 「Needs ID」（同定が必要）というフィルターを選択すると、同定が不足している観察が見つかりやすい

4. **観察を選択**:
   - 写真が明確で、同定可能な観察を選ぶ
   - すでに同定がされている場合は、それが誤っている可能性があるものを選ぶ

### ステップ2: 観察の詳細を確認

1. 観察写真をクリックして詳細ページを開く

2. **以下の点を確認**:
   - 写真が明確か
   - 特徴がはっきりしているか
   - 既存の同定が正しいか（誤っていたら改善のチャンス）

3. **分類学的情報を確認**:
   - キノコの場合：傘の形状、色、生息環境
   - 花の場合：花の形、色、葉の形状
   - 鳥の場合：体型、色、くちばしの形状
   - 昆虫の場合：翅の形状、体の色、模様

### ステップ3: 同定を追加または改善

#### ケースA: 同定が全くない場合

1. ページ下部の **「Add an identification」** ボタンをクリック

2. **分類名を入力**:
   - 可能な限り詳細に（種レベルが理想）
   - 例：「Veronica persica」（オオイヌノフグリ）
   - わからない場合は属レベルでもOK（例：「Veronica」）

3. **信頼度を選択**:
   - 「Something else」（その他）- 一般的な同定
   - 「I'm not sure」（自信なし）- 不確実な同定

4. **「Save」** をクリック

#### ケースB: 既存の同定を改善する場合（これが「改善ID」）

1. 既存の同定が**明らかに誤っている**場合:
   - 例：キノコを花と同定している
   - 例：誤った種名で同定されている

2. **「Add an identification」** をクリック

3. **より正確な分類名を入力**:
   - 既存の同定より詳細なレベルで
   - 例：既存が「Fungi」→ あなたは「Amanita muscaria」（ベニテングタケ）

4. **「Save」** をクリック

**重要**: これが「改善ID」としてカウントされます。

### ステップ4: 同定の質を高めるコツ

1. **自信があるものだけ同定する**:
   - 確実に識別できるものだけ
   - 迷ったら「I'm not sure」を選択

2. **可能な限り詳細に**:
   - 種レベル（species）が最も価値が高い
   - 属レベル（genus）でもOK
   - 科レベル（family）以上は避ける

3. **複数の角度から確認**:
   - 複数の写真がある場合は全て確認
   - 生態情報（生息環境、時期）も考慮

4. **参考資料を確認**:
   - iNaturalist内の類似した観察を参考にする
   - 信頼できるフィールドガイドを参照

## 「改善ID」の定義（重要）

**改善IDとカウントされるもの**:
- 既存の同定を**より正確なものに更新**した
- 誤った同定を**正しい同定に修正**した
- 曖昧な同定を**具体的な種名に改善**した

**改善IDとカウントされないもの**:
- 全く同定のない観察に新規で同定した（これは「新規同定」）
- 同じレベルの同定を別の候補として追加した
- 自信のない同定を追加した

## 目標: 10個の改善ID

### 効率的な方法

1. **「Needs ID」フィルターを使用**:
   - 同定が不足している観察が多数
   - 新規同定としてカウントされるが、コミュニティに貢献

2. **誤った同定を探す**:
   - 明らかに間違っている同定を見つける
   - それを修正することで改善IDになる

3. **毎日少しずつ**:
   - 1日2-3個の改善IDを目標
   - 約1週間で10個に到達

4. **あなたの得意分野を選ぶ**:
   - 花、キノコ、鳥、昆虫から選択
   - 知識がある分野で同定すると質が高い

## 確認方法

1. **プロフィールページ**にアクセス
2. **「Identifications」タブ**をクリック
3. **フィルターで先月を選択**
4. **「improved」ラベル**が付いているものを確認

または、統計情報で「他者のために作られた同定」の数を確認

## 注意事項

- **質を重視**: 自信のない同定は避ける
- **ガイドライン遵守**: iNaturalistのコミュニティガイドラインに従う
- **礼儀正しく**: 同定には根拠を示す
