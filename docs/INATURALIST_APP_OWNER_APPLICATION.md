# iNaturalist アプリ所有者申請ガイド

## 概要

iNaturalist APIの長期トークンを取得するには、事前に「アプリ所有者」として承認される必要があります。本ドキュメントでは、申請方法を説明します。

## 申請条件

1. **アカウント作成から2ヶ月以上経過していること**
   - あなたのアカウント作成日: 2026年4月7日
   - 2026年6月22日現在: 約2.5ヶ月経過 ✅ **条件を満たしています**

2. **先月に少なくとも10個の「改善ID」を追加していること**
   - 「改善ID」= 他のユーザーの観察に対する同定（Identification）の改善
   - 具体的には、誤った同定を正しい同定に修正する行為
   - 先月（2026年5月）に10件以上の改善IDが必要

## 「改善ID」の確認方法

1. iNaturalistにログイン
2. あなたのプロフィールページにアクセス
3. 「Identifications」タブをクリック
4. 先月の分を確認

**注意**: 「改善ID」は単に同定を追加するのではなく、**既存の同定をより正確なものに更新する**行為を指します。

## 申請方法

### 1. アプリケーションの概要を準備

申請時に以下の情報を記述する必要があります：

#### アプリケーション名
```
Name Nature
```

#### アプリケーションの説明
```
Name Natureは、自然写真を撮影してAIによる自動識別を行うモバイルアプリです。
iNaturalistのComputer Vision APIを利用して、花・キノコ・鳥・昆虫を識別し、
ユーザーが自身の観察記録を図鑑として保存・管理できます。

主な機能:
- カメラまたはライブラリからの写真読み込み
- iNaturalist APIによる自動種識別
- 候補の保存と図鑑管理
- 日本語/英語対応

このアプリは、ユーザーが撮影した写真をiNaturalist APIに送信し、
コンピュータビジョンによる候補を取得します。
ユーザーは候補から選択して自身の観察記録として保存できます。
```

#### APIの使用方法
```
1. ユーザーが写真を撮影または選択
2. アプリは写真をbase64エンコード
3. Cloudflare Workers経由でiNaturalist Computer Vision APIに送信
4. APIから候補リストを取得
5. ユーザーが候補を選択して図鑑に保存

使用するAPIエンドポイント:
- POST /v1/computervision/score_image - 画像による種識別
- GET /v1/taxa/{id} - 分類学的情報の取得

認証:
- OAuth 2.0を使用（Bearer トークン）
- スコープ: write（観察記録の作成のため）
```

#### ユーザーの関与
```
本アプリは完全に自動化されたシステムではありません。
ユーザーが実際に写真を撮影し、AIによる候補から適切な種を選択します。
すべての観察記録は人間の監視下で作成されます。
```

### 2. 申請の提出

1. [iNaturalist アプリケーション登録ページ](https://www.inaturalist.org/oauth/applications) にアクセス
2. 「アプリの所有者になるための申請」ボタンをクリック
3. 上記の情報を記入
4. 送信

### 3. 審査期間

- 審査には通常数日から数週間かかります
- 承認後、アプリケーション登録ページで「Register new application」が表示されるようになります

## 審査通過のコツ

1. **明確な用途説明**: アプリの目的と機能を明確に記述
2. **ユーザーの関与を強調**: 自動化ではなく、人間の監視があることを明記
3. **コミュニティガイドラインの遵守**: 自動生成されたコンテンツを作らないことを明記
4. **実用的なアプリ**: 実際に使用されるアプリであることを示す

## よくある質問

### Q: 「改善ID」が10個に満たない場合は？
A: 先月の分が10個未満の場合は、今月追加してから申請してください。

### Q: 審査は必ず通過しますか？
A: いいえ、審査を拒否する権利はiNaturalist側にあります。明確な用途とガイドライン遵守を強調してください。

### Q: 承認後、すぐに長期トークンを取得できますか？
A: はい。承認後、アプリケーション登録ページでClient IDとClient Secretを取得し、OAuthフローで長期トークンを取得できます。
